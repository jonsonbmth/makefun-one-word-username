One Word, One Username, One Reward — a tiny program that writes the
entrant's own make.fun username, one word and nothing else, to
`/output/entry.txt`. The username is `wwwwenwenwin`: twelve letters,
one word, no spaces, no padding.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when `OUTPUT_DIR`
is set). Python 3.13 standard library only, no network, deterministic.
